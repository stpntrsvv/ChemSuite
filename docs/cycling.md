# Циклирование в Chem Suite

BioLogic — основной формат. В верхнем тулбаре выберите «Циклирование».
«Открыть…» принимает несколько `.mpt`, `.mpr`, `.csv` или `.txt`: каждый файл
становится независимым опытом. «Рассчитать все» ставит опыты в последовательную
очередь. Ошибка одного файла не удаляет готовые результаты остальных.

«Очистить» в верхнем тулбаре убирает все опыты Cycling, графики и таблицы
из окна; EIS сохраняет своё состояние. Настройки анализа сохраняются, выбор
циклов и страница таблицы сбрасываются. Исходники, файлы результатов и экспорта
остаются на диске. Во время задания кнопка недоступна.

«Объединить файлы опыта…» создаёт один опыт с выбранными файлами в порядке,
возвращённом диалогом; список входов остаётся в request/provenance. Для точного
порядка нескольких частей можно передать список CLI. Папка FlowBat с
`config.json` и `01_Raw_data/potentiostat` тоже считается одним опытом; имена
файлов сортируются естественно (`2` перед `10`). Обычная папка загружает файлы
и непосредственные подпапки FlowBat как независимые опыты. Подпапки датчиков,
камеры, кадров и цвета не читаются. Исходники не модифицируются.

```bash
chem-suite run cycling analyze examples/biologic_cycling.mpt
chem-suite run cycling analyze part_01.mpr part_02.mpr --config '{"file_cycle_policy":"continue"}'
```

Для `.mpt` не нужны научные библиотеки. Для `.mpr` нужен extra `biologic`:

```bash
.venv/bin/python -m pip install -e '.[desktop,cycling,biologic,export]'
```

## BioLogic: каналы и циклы

MPT должен содержать сигнатуру EC-Lab/BT-Lab ASCII FILE, `Nb header lines`,
табличный заголовок, `time/s`, знаковый ток и напряжение. Поддерживаются
десятичная точка/запятая, UTF-8 и однобайтовые экспорты, дополнительные колонки.
Поля `mode`, `Ns`, `half cycle`, `cycle number` используются, если доступны.
MPR разбирается библиотекой galvani 0.5; проверены синтетические бинарные
модули данных версий 2 и 3 и публичная пара BT-Lab formation MPR/MPT.
Открытые GCPL/CCCV/GITT-записи и повторяемые проверки описаны в
[наборе тестовых данных](biologic-test-data.md). При неподдерживаемом варианте
MPR экспортируйте исходный опыт из EC-Lab как MPT. Для некоторых MPR
знаковый ток появляется только при текстовом экспорте. Совместимость с вашим
прибором и протоколом по-прежнему проверяется на его собственных файлах.

Автоматический выбор напряжения: `Ecell/V`, затем `Ewe-Ece/V`, затем
`Ewe/V` / `<Ewe>/V` / `<Ewe/V>` / `Ece/V`. Выбранное поле записывается
в метрики. **`Ewe` по умолчанию считается потенциалом электрода.** Для
двухэлектродной схемы, где именно Ewe измеряет полную ячейку, явно выберите
«Тип напряжения → Напряжение ячейки». В трёхэлектродной схеме выбирайте поле
напряжения ячейки. VE/EE и энергия ячейки не выдаются для потенциала электрода
или отрицательного напряжения; CE и ёмкость остаются доступны. Это различие
соответствует [описанию измерения ячейки с электродом сравнения BioLogic](https://biologic.net/wp-content/uploads/2019/08/reference-electrode_battery-an58.pdf).

Для тока поддерживаются `I/A`, `<I>/A`, `I/mA`, `<I>/mA`; миллиамперы
переводятся в амперы. Автоматический выбор предпочитает усреднённый ток, если
он есть; поле можно указать явно. Модуль тока `|I|` не заменяет знаковый ток.
`mode=3` обозначает паузу с открытой цепью: остаточный измеренный ток не
интегрируется в заряд. Ошибка прибора, нечисловые/нефинитные значения,
обратное время и отсутствие необходимых каналов останавливают этот опыт.
Спектры с `freq/Hz` нужно открывать в модуле EIS.

«Определение циклов → Автоматически» сохраняет `cycle number`, включая **0**.
Если счётчика нет, номер увеличивается при переходе разряд → заряд;
паузы и несколько CC/CV-шагов одного направления не создают новый цикл.
«По направлению тока» принудительно выбирает этот алгоритм. Дробный/сброшенный
внутри файла счётчик нельзя автоматически трактовать как номера полных циклов;
для таких записей выбирайте алгоритм по направлению тока.

Между файлами сброс/перекрытие номеров по умолчанию создаёт отдельные номера
анализируемых циклов. «Продолжать одинаковые номера» используйте только для
разделённых частей одного и того же цикла. Номера прибора и SHA256 каждого
источника сохраняются. Объединение файлов не восстанавливает потерянные измерения.

## Что рассчитывается

Для каждого активного шага интегрируются записанный ток и мощность методом
трапеций **внутри шага**:

- `Q_mAh = |∫ I_A dt_s| / 3.6`;
- `E_mWh = |∫ U_V I_A dt_s| / 3.6` для пригодного напряжения ячейки;
- среднее напряжение по заряду: `E_mWh / Q_mAh`;
- длительность, количество точек и исходные идентификаторы.

Интервалы между разными шагами без измеренных граничных точек не интегрируются
через предполагаемый скачок тока. Их длительность отмечается в диагностике.
Временная ось сохраняет `time/s` внутри файла. Разные файлы/локальные времена
шагов соединяются по записанной длительности; неизвестные реальные паузы
не добавляются. Из-за разреженной записи интегрирование может отличаться от
внутреннего накопленного заряда EC-Lab. Метод и временная конвенция записаны
в результате и отчёте. При смене `Ns`, режима, полупериода, направления или
номера цикла начинается отдельный шаг.

По каждому номеру суммируются все шаги заряда и разряда:

- `CE = 100 Qd/Qc`;
- `VE = 100 (Ed/Qd)/(Ec/Qc)`;
- `EE = 100 Ed/Ec = CE·VE/100`;
- использование номинальной ёмкости: `100 Qd/Qnom`;
- сохранение ёмкости: `100 Qd/Qd_reference`.

Наличие обоих направлений отмечается как «Есть заряд и разряд». Это не
доказывает достижение всех заданных в приборе конечных условий. Если направление
отсутствует или ёмкость нулевая, эффективности не вычисляются. Начатые и
оборванные записи сохраняются с доступными метриками; отсутствующие данные
не дополняются. Значения выше 100% не обрезаются.

Опорный цикл — первая записанная пара с ненулевым разрядом или явно указанный
номер. Номинальную ёмкость можно ввести в mAh. Для FlowBat конфигурация
`electrolyte.concentration_M`, `volume_ml`, `electrons_transferred` задаёт
`Qnom = n F c V / 3.6`, где объём переводится в литры; по соглашению FlowBat
`n=1`, если поле отсутствует. Все величины должны быть положительными.

Паузы содержат измеренную длительность, начало/конец напряжения и их разность.
«Напряжение в конце паузы» не является автоматической оценкой равновесного
потенциала. График U–Q показывает ёмкость от начала полупериода, суммируя
его CC/CV-шаги. Это не абсолютный SOC: начальное состояние заряда неизвестно.

## Просмотр, экспорт и сессии

По умолчанию рисуется до 10 равномерно выбранных циклов, включая первый и
последний. Поле «Циклы на графиках» принимает `0, 1, 5-10`;
«Показать выбранные циклы» строит новое представление в worker без повторного
разбора приборных файлов. Интерактивный выбор ограничен 50 циклами;
при количестве шагов больше 120 на графиках отображаются 120 равномерно
выбранных шагов по времени, включая первый и последний. Под графиками указано
показанное/полное число шагов. Метрики и экспорт сохраняют все шаги.
На кривую приходится до 2000 точек, общий бюджет — около 6000 точек на график.
Начальная и конечная точки сохраняются. Полные данные остаются в артефактах.
Таблицы циклов, шагов и пауз перелистываются страницами по 200 строк.

Панель содержит U–Q, U–t, I–t, CE/VE/EE, ёмкость заряда/разряда, сохранение
ёмкости, напряжение конца пауз, таблицы и сводку. RU/EN меняет подписи,
сохраняя числовые настройки и идентификаторы каналов.

Экспорт включает метрики циклов/шагов/пауз и полные измерения CSV,
книгу XLSX, JSON, отчёт, исходные снимки и PNG/SVG/PDF. По умолчанию
экспортируются **все циклы**, независимо от экранного выбора; настройка
«Циклы для экспорта → Выбранные циклы» применяет явное поле выбора.
В пакетном экспорте выбранные номера должны существовать в каждом опыте.
Переносимый result.json содержит полный научный результат/артефакты даже при
выборочном экспорте таблиц/графиков. Для переноса включайте копии источников и JSON.

Сохранение сессии включает готовые результаты всех опытов, выбранное
представление, настройки и SHA256 всех исходных файлов/config.json.
После открытия сессии или готового результата можно повторно рассчитать опыт
из архивных снимков без старых файлов. Отмена/ошибка не заменяет прежний готовый
результат и не публикует частичную папку экспорта. Датчики и камера отсутствуют.
