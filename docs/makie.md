# Экспериментальная графическая подсистема Makie

На этой машине Julia располагается внутри `.runtime/julia-1.13.1`; её пакеты и
кеши — внутри `.julia-depot`. Установки вне Chem Suite для этого прототипа не нужны.
На другой машине можно установить Julia самостоятельно и передать путь к бинарнику
через `CHEM_SUITE_JULIA`, а каталог пакетов — через `CHEM_SUITE_JULIA_DEPOT`.

```bash
export JULIA_DEPOT_PATH="$PWD/.julia-depot"
.runtime/julia-1.13.1/bin/julia --project=src/chem_suite/visualization/julia -e 'using Pkg; Pkg.instantiate()'
```

После расчёта нажать «Makie» в верхнем тулбаре. Qt асинхронно запускает отдельный Julia
процесс. Он остаётся запущенным для последующих графиков; данные загружаются из
готового result.json. WGLMakie/Bonito обслуживает страницу только на 127.0.0.1,
QtWebEngine показывает её внутри вкладки. Браузерный renderer работает в отдельном
процессе QtWebEngine. Julia не выполняет EIS/cycling и не разделяет с ними процесс.

Первый запуск включает загрузку и возможную компиляцию Julia; интерфейс продолжает
работать. Ошибка старта или остановка Makie выводится рядом с графиками, а анализы
модулей продолжаются. При закрытии приложения закрывается и Julia-сервис.

Экспорт SVG/PDF/PNG через CairoMakie также идёт отдельной задачей:

```bash
chem-suite run visualization makie /абсолютный/путь/к/result.json --timeout 600
```

Это прототип интеграции. До выбора основного renderer нужно измерить холодный/
повторный запуск, панорамирование, выделение точек, большие наборы данных, HiDPI и
упаковку. Сейчас Makie использует ограниченное PlotSpec-превью, как и Qt-графики;
оно не заменяет полные массивы для научного экспорта. У UI-сервиса пока нет LRU
очистки страниц; для очень длинных сессий это следующий этап.

Официальные источники API:
- https://docs.makie.org/stable/explanations/backends/wglmakie.html
- https://docs.makie.org/stable/explanations/backends/cairomakie.html
- https://bonito.sh/stable/deployment.html


Новые запросы WGLMakie получают подписи на выбранном языке RU/EN. Смена языка
уже открытой страницы требует нового открытия через кнопку Makie. Общий диалог
экспорта использует Matplotlib в отдельном worker и полные артефакты; CairoMakie
остаётся отдельным экспериментальным CLI-экспортом ограниченного PlotSpec-превью.
