# Открытые данные для проверки циклирования BioLogic

Записи скачиваются отдельно в `.runtime/public-biologic`, исключённый из Git.
Обычный `pytest` не использует сеть. Версии, размеры, контрольные суммы,
происхождение и атрибуция закреплены в
[`tests/public_data/biologic.json`](../tests/public_data/biologic.json).
Исходники данных сохраняются без изменения.

```bash
.venv/bin/python tools/fetch_biologic_test_data.py
CHEMSUITE_BIOLOGIC_TEST_DATA="$PWD/.runtime/public-biologic" \
  .venv/bin/python -m pytest tests/test_cycling_public_data.py -q
```

Для двух больших записей SINTEF (ещё около 128 MB):

```bash
.venv/bin/python tools/fetch_biologic_test_data.py --include-large
```

Открывайте каждый файл как отдельный опыт. `.mpr` и `.mpt` одной записи —
альтернативные представления, их нельзя объединять в один опыт: измерения
будут посчитаны дважды. Для MPR установлен extra `biologic`.

## GitHub: Galvani

[Galvani, закреплённый commit d4a5f44](https://github.com/echemdata/galvani/tree/d4a5f444b16eae57d2edfad6df774ead95c92fd6/tests/testdata).
Лицензия тестовых данных — **CC BY 4.0**, Christopher Kerr, 2010–2014;
[декларация лицензии](https://github.com/echemdata/galvani/blob/d4a5f444b16eae57d2edfad6df774ead95c92fd6/.reuse/dep5).
Файлы опубликованы через Git LFS; загрузчик получает сами записи и проверяет
их SHA256, а не сохраняет текстовые LFS-указатели.

| Запись | Что проверяет | Проверенный результат |
| --- | --- | --- |
| `020-formation_CB5.mpr` / `.mpt` | BT-Lab, CC/CV, паузы, длинный однобайтовый заголовок | 1323 точки, 11 шагов, 5 пауз, 2 цикла |
| `v1150_GCPL.mpt` | EC-Lab 11.50, десятичная запятая, нулевой номер цикла | 132 точки, 4 цикла, 4 паузы |
| `v1150_GCPL.mpr` | Отсутствие знакового канала тока в бинарной записи | Явная ошибка; следует использовать парный MPT |

Для formation ёмкости по записанным точкам в MPT:

| Цикл прибора | Заряд, mAh | Разряд, mAh |
| --- | --- | --- |
| 0 | 62.16546124 | 50.84896300 |
| 1 | 51.42257647 | 49.64532294 |

Бинарный и текстовый варианты совпадают по ёмкости с относительной разницей
меньше `10⁻⁸`. Значения также сверены с независимыми накопленными колонками
`Q charge/mA.h` и `Q discharge/mA.h`: расхождение менее 0.5%.
Трапеции по сохранённым точкам и внутренний интегратор прибора имеют разные
правила на границах шагов, поэтому точного равенства с этими колонками нет.

MPR не содержит экспортный `cycle number`: автоматическая нумерация даёт 1, 2,
а MPT сохраняет номера прибора 0, 1. Тест сравнения явно выбирает определение
циклов по направлению тока. Кроме того, galvani называет бинарный канал
`Ewe/V`, тогда как BT-Lab экспортирует `Ecell/V`. Chem Suite сохраняет эти
имена; для MPR тип напряжения ячейки задаётся явно после проверки схемы подключения.
Ток из `dq` или команды прибора автоматически не восстанавливается.

## Zenodo: SINTEF

[Battery Datasets for Testing Data Pipelines and Workflow Automation,
версия 0.7.1](https://zenodo.org/records/18986774), DOI `10.5281/zenodo.18986774`.
Лицензия **CC BY 4.0**. Авторы: Simon Clark, Julian Tolchard, Dennis Kopljar,
Christina Schmitt, Elias Barbers.

- `SINTEF__NaCR32140-MP10-04__2025-08-25__GITT_0p05C_25degC__BioLogic.mpt`:
  GITT натрий-ионной полной ячейки, импульсы и паузы; 74.7 MB.
  Проверено: 157985 точек, 227 шагов, 115 пауз, один цикл с номером 0.
  Заряд 11091.62626 mAh, разряд 11072.84400 mAh, CE 99.83066%, EE 97.33514%.
  Расхождение с накопленными ёмкостями BT-Lab менее 0.003%.
  Полный импорт через worker сохраняет все точки; экран показывает 120 из
  227 шагов с явной пометкой. Экспорт и таблицы не ограничены числом шагов превью.
- `SINTEF__NaCR32140-MP10-04__2025-08-25__CCCV_0p02C_25degC__BioLogic__Outlier_Bug.mpt`:
  CCCV при C/50; 53.6 MB. **Авторы намеренно сохранили выбросы тока и напряжения.**
  Запись служит проверкой обработки проблемных данных, а не эталоном чистой кривой.
  В ней 112834 точки и флаг ошибки прибора на строке данных 69922:
  Chem Suite останавливает импорт этого опыта, не публикуя успешный результат.
  Отказ закреплён отдельным тестом; исходная запись не очищается автоматически.

Набор независим от наших синтетических примеров. Он не заменяет сверку с
конкретным лабораторным прибором, его прошивкой и протоколом опыта.
