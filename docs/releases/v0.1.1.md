## Русский

Chem Suite теперь проверяет стабильные GitHub Releases и предлагает обновления.
В меню «Справка» появились ручная проверка и настройка автоматической проверки.
Скачивание не блокирует интерфейс; перед установкой проверяются размер и SHA256 файла.
Можно отменить скачивание или отложить установку. Во время расчёта установка недоступна.

Windows запускает установщик в текущую папку приложения. На macOS открывается DMG:
перетащите Chem Suite в «Программы» и подтвердите замену. Сохраните рабочую сессию
перед перезапуском; папки данных и результаты расчётов сохраняются.

Если у вас версия 0.1.0, установите 0.1.1 вручную один раз — предыдущая версия ещё
не содержит проверки обновлений. Следующие версии будут предлагаться приложением.

Сборки пока без подписи издателя; Julia/Makie устанавливаются отдельно.

## English

Chem Suite now checks stable GitHub Releases and offers updates.
Help includes manual checking and an automatic-check preference.
Downloads keep the UI responsive and verify file size and SHA256 before installation.
Downloads can be cancelled and installation deferred. Installation is disabled during analysis.

Windows opens the installer in the current application directory. On macOS the DMG
opens: drag Chem Suite to Applications and confirm replacement. Save your session
before restarting; data directories and calculation results are preserved.

Version 0.1.0 users need to install 0.1.1 manually once; future versions will be offered
by the application. These builds have no publisher signing; Julia/Makie are optional external installations.
