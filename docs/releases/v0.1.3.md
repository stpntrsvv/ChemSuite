## Русский

- Исправлено чтение BioLogic GCPL без отдельной колонки тока. Ёмкость считается
  по записанному `dq`; средний ток за интервал явно обозначен. Энергия, VE и EE
  недоступны, когда измерений недостаточно для их определения.
- При экспорте PNG/SVG/PDF можно разместить легенду под графиком, внутри или
  скрыть. Для циклирования по умолчанию легенда находится под графиком.
  Все кривые и численные данные сохраняются при любом варианте.
- Перед установкой обновления можно сохранить рабочую сессию: данные, результаты,
  настройки обоих модулей, язык и выбор легенды. При следующем запуске программа
  предложит восстановление без повторных расчётов. Резервные копии остаются
  на вашем компьютере; отмена или ошибка сохранения не закрывают приложение.

Новое сохранение перед обновлением работает начиная с этой версии. Перед переходом
с 0.1.2 сохраните текущую сессию через меню «Файл»; 0.1.0/0.1.1 обновите вручную.
Windows: обычный установщик или portable ZIP. macOS: откройте DMG и перенесите
Chem Suite в «Программы». Сборка Mac предназначена для Apple Silicon.
Приложения пока без подписи издателя; Julia/Makie устанавливаются отдельно.

## English

- Fixed BioLogic GCPL import when a signed current column is absent. Capacity uses
  recorded `dq`; interval-mean current is labelled explicitly. Energy, VE and EE
  remain unavailable when the measurements cannot determine them.
- PNG/SVG/PDF export offers legends below the plot, inside, or hidden. Cycling
  defaults to below the plot. All curves and numerical data are retained.
- Updates can save a local session before installation, including both modules'
  data, results, settings, language and legend choice. The next launch offers
  restoration without recalculating. Cancelled or failed saving keeps the app open.
  Recovery copies stay on your computer.

The new save-before-update flow starts with this version. Save your current session
through File before upgrading from 0.1.2; upgrade 0.1.0/0.1.1 manually. Windows offers
an installer and a portable ZIP. On macOS, open the DMG and drag Chem Suite to
Applications. The Mac build targets Apple Silicon. Builds have no publisher signing;
Julia/Makie remain optional external installations.
