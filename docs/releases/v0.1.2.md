## Русский

Исправлено перенаправление скачивания GitHub Releases в PySide: проверка обновлений
теперь действительно читает манифест с CDN GitHub. Нативные сборки Mac и Windows
проверяют настоящий канал обновлений перед выпуском, включая TLS и перенаправление.

В меню «Справка»: «Проверить обновления» и настройка автоматической проверки.
Программа проверяет новые стабильные версии при запуске, не чаще раза в сутки,
показывает изменения и предлагает скачивание. Файл проверяется по размеру и SHA256;
скачивание можно отменить, а установку отложить. Установка недоступна во время анализа.
Windows открывает установщик; macOS открывает DMG для замены приложения вручную.
Перед перезапуском сохраните рабочую сессию. Данные и сохранённые результаты остаются.

Версии 0.1.0 и 0.1.1 нужно один раз обновить до 0.1.2 вручную; в 0.1.1
найдена ошибка чтения манифеста. Следующие версии будут предлагаться приложением.
Сборки пока без подписи издателя; Julia/Makie устанавливаются отдельно.

## English

Fixed GitHub Releases redirects in PySide: update checking now reads the actual
manifest from GitHub's CDN. Native Mac and Windows builds test the real public
feed, TLS and redirect handling before publication.

Help includes manual checking and an automatic-check preference. Packaged builds
check newer stable versions at startup at most once per day, show release notes and
offer cancellable downloads with size and SHA256 verification. Installation can be
postponed and is disabled during analysis. Windows opens the installer; macOS opens
a DMG for manual replacement. Save your session before restarting; data and saved
results remain in their folders.

Version 0.1.0 and 0.1.1 users need to install 0.1.2 manually once; later versions will
be offered in the app. Version 0.1.1 has a manifest redirect bug. Builds have no publisher
signing; Julia/Makie are optional external installations.
