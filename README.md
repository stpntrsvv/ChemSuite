# Chem Suite

Новая общая платформа для EIS и циклирования. Первая рабочая версия: два независимых
расчётных модуля, оболочка Qt, CLI, изолированные задачи и общий формат графиков.

## Запуск

```bash
cd /Users/stpntrsvv/chemsuite
source .venv/bin/activate
chem-suite gui
```

Для установки на другой машине:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[desktop,eis,biologic,cycling,export,dev]'
```

Выберите EIS или циклирование в верхнем тулбаре: модуль открывается в том же окне.
Кнопки открытия, расчёта и отмены относятся к выбранному модулю. Переключение
сохраняет данные, настройки и результаты; задачи GUI выполняются по очереди.
Общий журнал задач открывается кнопкой в тулбаре.
«Очистить» убирает все загруженные опыты и результаты **выбранного модуля**
из окна. Настройки анализа, исходники, сохранённые результаты и журнал задач
сохраняются. Во время задания или работы с сессией очистка недоступна.

Примеры находятся в `examples/`: EIS — `eis_double_cpe.txt`, циклирование — `cycling.csv` и синтетический BioLogic `biologic_cycling.mpt`.
Реальные открытые записи BioLogic и команды повторной проверки:
[тестовые данные Galvani и SINTEF](docs/biologic-test-data.md).

```bash
chem-suite modules
chem-suite run eis fit examples/eis_double_cpe.txt --config '{"circuit":"R0-p(R1,CPE0)-p(R2,CPE1)"}'
chem-suite run cycling analyze examples/cycling.csv
```

Пакет без extras устанавливает только ядро и CLI. Циклирование использует стандартную
библиотеку: оно работает без NumPy, SciPy, impedance, Qt и Julia. EIS extras устанавливаются
отдельно; отсутствие или сбой зависимости EIS отображается как ошибка его задачи.

## Что уже работает

- Рабочая панель EIS по образцу исходного Solver: список спектров и кандидаты
  схем слева, графики и диагностика справа, изменяемые размеры панелей,
  скрытые настройки схемы и начальных приближений в Pro mode.
- Русский и английский интерфейс: меню «Язык», выбор сохраняется для рабочего каталога.
- EIS: чтение текстовых спектров и BioLogic (с extra `biologic`), выбор канала,
  Lin-KK, явная схема или адаптивный выбор, параметры и диагностические флаги.
- Циклирование: BioLogic `.mpt`/`.mpr`, нормализованный CSV, YARST, Elins/ES8
  и папки FlowBat. Отдельная панель опытов, пакетная загрузка и экспорт,
  CC/CV-шаги и паузы, CE/VE/EE, U–Q/U–t/I–t, ёмкость и её сохранение.
  Выбор каналов BioLogic и циклов, страницы таблиц, повторный расчёт из сессии.
  [Работа с циклированием и ограничения](docs/cycling.md).
- Общие быстрые Qt-графики через pyqtgraph: масштабирование, панорамирование,
  связанные оси частоты на АЧХ и ФЧХ. Контекстное меню управляет видом графика.
- Загрузка нескольких спектров или папки с подпапками, превью и KK до подбора,
  последовательный пакетный расчёт и отдельные ошибки файлов.
- Экспорт текущего или всех готовых EIS результатов: CSV, XLSX, JSON, отчёт,
  исходники с SHA256 и графики PNG/SVG/PDF. Экспорт готового циклирования доступен
  в том же тулбаре. Подробности: [docs/workflows.md](docs/workflows.md).
- Просмотр любой сошедшейся схемы из таблицы кандидатов: собственные графики и параметры,
  отдельно от статистического победителя. Пользовательские пресеты сохраняются в рабочем каталоге.
- Проверка выбора схемы: остаточный bootstrap, устойчивость DRT, исходные правила
  рекомендации и отказа, импорт полного inference JSON и экспорт свидетельств.
- Проверка параметров: остаточные/параметрические повторные выборки, интервалы 95%,
  профиль правдоподобия и устойчивость к частотному окну; всё в отдельных процессах.
- Редактор начальных значений и границ параметров с единицами, бюджет оптимизации
  и seed. Настройки сохраняются в запросе результата и действуют для выбранной схемы.
- DRT: неотрицательное распределение, выбор регуляризации на отложенных частотах,
  пики, опциональная проверка их устойчивости, отдельные результаты и экспорт.
- SPICE: проверенный пакет model.lib + passport.json, отдельной командой EIS
  или флажком общего экспорта. Для публикации требуется доступный ngspice
  и прохождение научных и инженерных проверок.
- EIS-графики: Nyquist, Боде (модуль и фаза), абсолютные и относительные остатки,
  Lin-KK и его остатки. Параметры сопровождаются стандартной ошибкой оценки 1σ.
- Экспериментальный WGLMakie в QtWebEngine и отдельный экспорт CairoMakie:
  [настройка и ограничения](docs/makie.md).
- Артефакты задач: `result.json`, `job.json`, копии исходников с SHA256 и полные данные.
  По умолчанию они хранятся в `.chem-suite/jobs/`; параметр `--workspace` меняет расположение.

Превью EIS ограничено 2000 точками на серию. Cycling по умолчанию показывает
до 10 циклов, включая начало и конец опыта; можно явно выбрать другие циклы.
Таблицы разбиты на страницы по 200 строк. Эти ограничения не относятся к экспорту.
Полные измерения и метрики сохраняются независимо от превью. Для расчётов превью не используется.

## Границы первой версии

Научные функции исходного EIS Solver перенесены: подбор и проверка схем,
DRT, диагностика параметров, SPICE и C-пакеты float32/Q1.31, анализ серий,
совместный подбор по SOC, синтетическая карта разрешимости и исследовательские
benchmark-конвейеры. Обычные режимы доступны в окне EIS; исследовательские
корпуса и проверки запускаются через изолированный CLI. Подробности и ограничения:
[docs/workflows.md](docs/workflows.md).

В меню «Файл» доступны сохранение/открытие переносимой сессии и открытие
готового `result.json`. Сессия содержит исходные снимки и артефакты; её можно
перенести, даже если старое рабочее место и исходные файлы недоступны.

Cycling поддерживает независимые эксперименты и явное объединение файлов
одного опыта. Датчики и камера исключены из объёма проекта. Неизвестные
промежутки между файлами не восстанавливаются из предположений. Общая модель образцов/ячеек и связывание EIS
с номером цикла ещё не реализованы. Сохранённые научные результаты открываются из меню «Файл»; автосохранение
при аварийном закрытии приложения пока не добавлено.

Численный baseline EIS сохранён в `modules/eis/legacy`; оптимизация вычислителя
схем и C++ пока не вводились. Для циклирования энергию считаем непосредственно
как интеграл U·I по времени, поэтому на нерегулярной сетке результат отличается
от приближения старого циклирования «среднее напряжение × ёмкость».

Проверена разработческая версия на macOS arm64. Упакованные приложения для
macOS/Windows ещё не собирались; на Windows остановка дерева внешних процессов
потребует отдельной проверки и адаптера Job Objects.
